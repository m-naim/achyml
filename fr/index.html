Pourquoi achyml ?

Les schémas d'architecture logicielle traditionnels sont cassés. Voici notre solution.

Le Problème

Dessins Statiques et Périmés

Les schémas sur Miro, Figma ou Lucidchart sont des dessins figés. Ils deviennent obsolètes dès que le code change car déplacer des rectangles à la main est contraignant.

↓
Notre Solution

Architecture as Code (AaC). Déclarez vos services dans des fichiers YAML stockés avec votre code. Votre diagramme reste synchronisé avec Git automatiquement.

Le Problème

Ajustements Manuels Pénibles

Les développeurs perdent des heures à aligner les boîtes et réorganiser l'ensemble du canevas pour insérer une simple nouvelle boîte au milieu du schéma.

↓
Notre Solution

Placement sur Grille Automatique. Définissez vos composants par niveau vertical (level) et colonne (column). L'outil gère l'alignement et les connexions proprement.

Le Problème

Liaisons Floues "Boîte à Boîte"

Les schémas classiques relient de grands blocs globaux, masquant quelles API ou méthodes de contrôleurs ciblent concrètement quelles tables SQL.

↓
Our Solution

Dépendances Ultra Précises. Reliez directement vos endpoints à des tables SQL. Affichez les liens de haut niveau ou isolez les chaînes d'appel complètes en un clic.

schema-src/components/auth-service.yaml
id: svc-auth
type: microservice
name: auth-service
level: 1
column: 1
elements:
  - id: route-login
    type: route
    method: POST
    path: /login
    dependencies:
      - to: collection-users
        label: writes
