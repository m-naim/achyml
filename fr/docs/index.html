Documentation achyml

Découvrez comment déclarer des architectures système modulaires en YAML et synchroniser vos fichiers en temps réel.

Synchronisation & Assemblage de Dossier

achyml vous permet d'éditer des fichiers localement dans votre éditeur favori (VS Code, Vim, Sublime Text) et de voir les mises à jour graphiques en temps réel. Grâce à l'API moderne File System Access, le navigateur communique directement avec votre espace de travail local.

Comment configurer la synchronisation locale

  1. Créez un dossier sur votre ordinateur (ex: mon-architecture).
  2. À l'intérieur, créez votre fichier de configuration principal (ex: main.yaml) et un ou plusieurs fichiers de composants (ex: auth-service.yaml).
  3. Ouvrez achyml dans Chrome ou Edge, cliquez sur "Choose Folder" dans le panneau de synchronisation à gauche, et sélectionnez votre dossier.
  4. Choisissez main.yaml dans le menu déroulant. Le navigateur analyse le répertoire, détecte les composants et les assemble à la volée.
  5. Cochez la case "Live Sync". Désormais, chaque fois que vous sauvegardez un fichier de ce dossier dans VS Code, le navigateur compile et met à jour votre diagramme instantanément.
ℹ️ Note de sécurité : Chrome demande l'autorisation d'accès au dossier après un rechargement complet de la page. Cliquer sur "Choose Folder" rouvrira le dernier dossier sélectionné en un seul clic.

Structure & Spécification du YAML

Votre diagramme est calculé à partir de propriétés YAML. Voici la spécification pour le fichier principal et les composants individuels.

Fichier Principal (Main)

Ce fichier définit les métadonnées globales et les liens reliant les éléments de vos services :

version: 1
components: []   # Peut être déclaré en ligne, ou laissé vide lors du chargement modulaire
links:
  - id: auth-to-db
    from: route-login
    to: collection-users
    label: writes

Structure d'un composant (Fichier individuel)

Chaque composant (comme un microservice ou une base de données) est déclaré avec ses coordonnées et ses éléments internes :

id: svc-auth
type: microservice     # Choix : gateway, microservice, sql, mongodb, queue, cache, api
name: auth-service
level: 1               # Niveau vertical (1 = ligne du haut, 2 = deuxième ligne, etc.)
column: 1              # Position horizontale (1 = première colonne, etc.)
elements:              # Éléments imbriqués (ex: routes d'API, tables de base de données)
  - id: route-login
    type: route
    method: POST
    path: /login
  - id: route-register
    type: route
    method: POST
    path: /register

Règles des Liaisons & Dépendances

achyml trace des flèches fines entre les blocs. Suivez ces directives pour écrire des liaisons valides :

Liaisons Élément à Élément

Pour des diagrammes détaillés et précis, reliez l'identifiant exact d'une route ou d'une méthode à une collection ou table de base de données en utilisant leur id. Le chemin se connectera élégamment sur les bordures.

Liaisons Composant à Composant

Si vous spécifiez un lien reliant l'ID global d'un composant parent (ex: from: svc-auth au lieu de route-login), le moteur :

  • Résoudra automatiquement la liaison sur le premier élément interne déclaré dans le composant.
  • Si le composant ne contient aucun élément, le compilateur affichera une erreur vous demandant d'ajouter au moins un élément pour pouvoir attacher le lien.

Raccourcis Clavier

Accélérez votre processus de conception grâce à ces raccourcis intégrés :

Raccourci Description de l'action
A Ajouter composant — Ouvre le menu d'ajout de bloc
P Vue parents uniquement — Masque les éléments pour n'afficher que les boîtes principales
C Filtre de chaîne — Isole les flux d'appels amont/aval de l'élément sélectionné
Esc Désélectionner — Annule la sélection et recentre la vue
H Documentation — Ouvre le tiroir d'aide rapide
