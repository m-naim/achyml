achyml Documentation

Learn how to declare modular system architectures using YAML and synchronize files live in your browser.

Folder Synchronization & Bundling

achyml allows you to edit files locally in your favorite editor (VS Code, Vim, Sublime Text) and see visual diagram updates in real-time. By utilizing the modern File System Access API, the browser communicates directly with your local workspace.

How to setup local sync

  1. Create a folder on your computer (e.g. my-architecture).
  2. Inside, create your main configuration file (e.g. main.yaml) and one or more component files (e.g. auth-service.yaml).
  3. Open achyml in Chrome or Edge, click "Choose Folder" under the Folder Sync panel, and choose your folder.
  4. Select main.yaml in the dropdown. The browser will scan the directory, find all component files, and compile them on the fly.
  5. Check the "Live Sync" box. Now, saving any file inside the directory in VS Code instantly re-bundles and updates your diagram.
ℹ️ Caching and security note: Chrome requires folder permissions again after a full page refresh. Clicking "Choose Folder" remembers your last folder, making re-linking a single-click action.

YAML Structure & Specification

Your diagram is computed from a set of YAML properties. Below is the specification for the main entry file and component models.

Main Configuration File

This file defines global metadata and links connecting elements across services:

version: 1
components: []   # Can be declared inline, or left empty if loading modular files
links:
  - id: auth-to-db
    from: route-login
    to: collection-users
    label: writes

Component File Schema

Each component (like a microservice or database) is declared with its grid coordinates and internal elements:

id: svc-auth
type: microservice     # Options: gateway, microservice, sql, mongodb, queue, cache, api
name: auth-service
level: 1               # Grid depth / row (1 = top row, 2 = second row, etc.)
column: 1              # Horizontal alignment column (1 = first column, etc.)
elements:              # Nested items in the box (e.g., API endpoints, DB collections)
  - id: route-login
    type: route
    method: POST
    path: /login
  - id: route-register
    type: route
    method: POST
    path: /register

Connection & Dependency Mapping

achyml traces fine-grained arrows between components. When writing links, follow these resolving guidelines:

Element-to-Element Links

For precise diagrams, connect the specific route/method to a database table or collection using their internal id. The path will attach on the boundaries and curve cleanly.

Component-to-Component Links

If you specify a link from/to a parent component ID (e.g. from: svc-auth instead of route-login), the layout engine will:

  • Automatically resolve it to the first element found in that component's elements array.
  • If the component has no elements, the compiler displays a warning instructing you to add an element to attach links.

Keyboard Shortcuts

Accelerate your visual building workflow with these key shortcuts:

Shortcuts Action description
A Add Component — Opens component insertion menu
P Toggle Parents View — Collapses components to show component-only connections
C Toggle Chain Filter — Isolates all upstream/downstream paths for selected element
Esc Deselect — Clears selected elements and zooms out to fit diagram
H Documentation — Opens the quick help drawer modal
